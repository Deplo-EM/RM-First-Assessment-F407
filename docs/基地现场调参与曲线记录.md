## 二、第一步：开环标定（先量"电机的脾气"，再谈调参）

**做法**：编一个**不闭环**的固件（`-DOPENLOOP_VOLT=<固定电压>`），只往电机发一个固定电压，
读 `g_fb_speed_rpm`。这样**不可能失控**，是最安全的起步方式。

| 电压给定 | 实测转速 | 说明 |
|---|---|---|
| +600 | 约 15 rpm（实测）| 已在转动，但推得不太动 |
| +1500 | 约 15 rpm（实测）| 和 600 差不多 → 小电压区间受齿槽力影响，非线性 |
| +8000 | 约 50 rpm（由闭环曲线推算）| 大约 **每 1000 单位 ≈ 6~10 rpm** |

**这一步还确定了符号**（很重要）：

> 正电压 → **正转速** ✓
> 所以后面那次的"爆转"**不是正负号接反**（正反馈），而是**增益给得太大**。

## 三、速度环：从最小增益逐级往上（每次只改一个数）

| 档位 | kp | ki | 输出上限 | 现象 | 结论 |
|---|---|---|---|---|---|
| L1 | 30 | 0 | 3000 | 稳，但只跟到目标约 30% | 太软 |
| L2 | 60 | 0 | 3000 | 稳，约 55% | 可用 |
| L3 | 120 | 0 | 3000 | **板子反复重启** → Timeline 上目标正弦变成"锯齿" | 环路失稳 ✗ 弃用 |
| M1 | 60 | 50 | 3000 | 稳，与目标的差距开始被补齐 | 观察 |
| **M2** | **60** | **150** | 3000 | 稳、贴合明显变好，波峰开始有轻微毛刺 | 速度环定案 ✓ |
| N1 | 60 | 150 | 8000 | 正式参数（±60 rpm / 0.2 Hz），跟随约 83% | **→ 截图①** |

### 两个关键判读经验

1. **"目标正弦变锯齿" = 板子在反复重启**，不是目标函数坏了。
   原理：每次重启，正弦的相位被清零 → 只画出"从 0 涨上去"的那一小段 → 连起来就是锯齿。
   **判据**：把 `uwTick`（板子的毫秒计时器）也加进采样 —— 锯齿状 = 在重启。
2. **输出上限只是"天花板"，不是稳定性的根源**。
   爆转的根源是 **kp（环路强度）**；上限的作用是"万一失控时的最坏程度"。
   所以调参时应该：**先压住上限保安全，再慢慢加 kp**。

## 四、位置环：先"变硬"，再"治死区"

| 档位 | kp_pos | ki_pos | 上限 | 目标振幅 | 现象 | 结论 |
|---|---|---|---|---|---|---|
| P1 | 2000 | 0 | 1500 | 0.5 rad | 输出**没顶到上限**，但电机被齿槽力吸住 → **"停—走—停"方块波** | 力气不够 |
| **P3** | **15000** | 0 | 5000 | 0.5 rad | **两条线完全贴合** ✓ | 位置环定案 ✓ |
| **R2** | **15000** | 0 | 8000 | **1.5 rad** | 两条线几乎重合，实物摆动也明显 | **→ 截图②** |

### "停—走—停"是什么

这叫 **粘滑（stick-slip）**，本质是 **摩擦死区**：

```
电机静止 → 齿槽力把它吸住
比例(P)项只在"有误差"时才出力 → 误差一小，力就小 → 推不动
目标继续走 → 误差越积越大 → 攒够了 → "咔"一下弹过去
弹过去后力又变小 → 再次卡住 → 停—走—停
```

**解法**：加大 kp（变硬）或加**积分(I)**（把历史误差一直攒着，直到把电机顶过去）。
本次靠"加大 kp"就解决了；若加大 kp 后仍走走停停，应改用带积分的档位。

## 六、源码里对应的开关（`App/ControlTask.cpp`）

```cpp
#define PID_KP_SPEED   60.0f     // 速度环比例（现场实测的稳定值）
#define PID_KI_SPEED   150.0f    // 速度环积分（再大会在波峰起尖刺）
#define PID_KP_POS     6000.0f   // 位置环比例（交付的位置档用 -D 覆盖为 15000）
#define PID_KI_POS     3000.0f   // 位置环积分（交付的位置档用 -D 覆盖为 0）
#define PID_VOLT_LIMIT 8000.0f   // 输出上限（满量程 25000 的 32%）
#define SPEED_AMP      60.0f     // 速度目标振幅（rpm）
#define POS_AMP        1.0f      // 位置目标振幅（rad；交付用 -D 覆盖为 1.5）
#define BRINGUP_STAGE  2         // 0=只观测 / 1=小幅值 / 2=正式参数
#define RUN_MODE       0         // 0=速度环 / 1=位置环
```

**设计要点**：所有可调量都是 `#ifndef ... #define ...` 的**编译开关** ——
同一份源码，靠 `-D` 覆盖就能编出各种档位的固件，**不用改代码**，也便于回溯"哪张图是哪档参数出的"。

## 七、踩过的两个坑（留给以后）

1. **调试会话没开始 = 什么都不会动**。
   Ozone 里必须 `Debug → Start/Stop Debugging`（或 **F5**）让程序真正跑起来（状态栏出现 `CPU running`），
   否则 CPU 停着，看到的变量全是死的 —— 会误判成"通信坏了 / 电机没电"。
2. **增益不能一步跳太大**。
   本次从"完全不转"直接跳到 kp=150，结果电机爆转。
   正确做法：**开环标定 → 小增益闭环 → 每次只改一个数、成倍递增 → 每步都看曲线确认**。
